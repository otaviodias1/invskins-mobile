# Frontend — React Native

Esta pasta está reservada para o aplicativo mobile. O projeto React Native ainda
não foi inicializado; portanto, ainda não há comandos de instalação ou execução.

O aplicativo consumirá a API HTTP/JSON do Spring Boot em `../backend/`.
O acesso ao banco de dados fica sob responsabilidade do backend.

Ao implementar o app, organize o código em `src/screens/` (telas),
`src/components/` (componentes compartilhados) e `src/services/` (chamadas à API).

As páginas HTML/Thymeleaf existentes pertencem ao backend e precisarão ser
implementadas como telas React Native para uso no aplicativo.
